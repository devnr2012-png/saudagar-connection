# SaudagarConnection (सौदागर कनेक्शन) ### Direct B2B Wholesaler & Retailer Trade Matchmaking Web App A responsive, zero-dependency Single-Page Web Application built with **HTML5, Tailwind CSS, and Vanilla JavaScript** designed for instantaneous deployment on **GitHub Pages**. --- ## 🚀 Live GitHub Pages Deployment Guide To host this app on GitHub Pages in under 2 minutes: 1. **Create / Push to GitHub**: ```bash git init git add index.html README.md git commit -m "Deploy SaudagarConnection Web App" git branch -M main git remote add origin https://github.com//.git git push -u origin main ``` 2. **Enable GitHub Pages**: - Go to your repository settings: `Settings > Pages`. - Under **Build and deployment > Source**, select **Deploy from a branch**. - Under **Branch**, select `main` (or `master`) and folder `/ (root)`. - Click **Save**. - Your live URL will be ready at: `https://.github.io//` --- ## 🌟 Key Features Implemented ### 1. Dual-Role Architecture - **Retailer Sourcing Mode**: Store and Kirana owners can search, filter by market hubs (Sadar Bazar, Khari Baoli, APMC Vashi, Surat Textile Hub), inspect verified distributors, and send direct quotations. - **Wholesaler Distribution Hub**: Stockists can track live buyer demand volume, review incoming RFQs, and activate their verified profile in under 1 minute with **Zero Catalogue Upload Needed**. ### 2. Direct WhatsApp RFQ (Request For Quotation) - Generates commercial B2B inquiries (products required, carton/truckload quantities, delivery pincode, store name) with direct one-tap opening in WhatsApp (`api.whatsapp.com`). ### 3. "3 Free Contact Unlocks" Trial Engine - Retailers receive **3 Free Trial Unlocks** to reveal direct phone numbers and exact warehouse addresses with zero upfront fee. - Instant fallback to ₹49 Razorpay/UPI/Google Pay simulator once trial quota is used. ### 4. Interactive Voice Search - Voice search modal with animated pulsating microphone waveforms and quick prompts in Hindi and English (e.g., *"Tata Tea Wholesaler Sadar Bazar"*, *"Surat Cotton Sarees Direct Mill Rate"*). ### 5. Trust & Verification Signals - **Direct Mill Rate & 10+ Years Mandi Standing Badges**. - 100% GSTIN, Justdial, and Udyam verification badges. - Response time and same-day dispatch SLAs. --- ## 🛠️ Tech Stack - **HTML5**: Semantic layout with accessible modal dialogs and inputs. - **Tailwind CSS (CDN)**: Modern responsive styling with custom Navy, Gold, and WhatsApp color palettes. - **FontAwesome 6**: Clean B2B and trade icons. - **Vanilla JavaScript**: State management, live search filtering, modal management, and dynamic local persistence.
